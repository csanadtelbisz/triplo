# Agent instructions

Run all `npm` and `npx` commands with `frontend/` as the working directory. This
includes installing dependencies, starting development or preview servers,
building, linting, and running tests. The `package.json` and `package-lock.json`
are in `frontend/`; there is no npm package at the repository root.

Set the command tool's working directory to `frontend/`, or run `cd frontend`
from the repository root before issuing npm or npx commands.
